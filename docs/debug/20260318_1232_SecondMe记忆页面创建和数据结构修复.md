### 3. 更新 services.js

#### 添加 getSoftMemories 方法
```javascript
async getSoftMemories() {
    const token = await this.getValidAccessToken();
    if (!token) throw new Error('未登录 SecondMe');
    
    try {
        const response = await fetch(`${API_BASE}/secondme/softmemory?pageNo=1&pageSize=200`, {
            method: 'GET',
            headers: { 
                'Authorization': `Bearer ${token}`, 
                'Content-Type': 'application/json' 
            },
        });
        const result = await response.json();
        if (result.code === 0 && result.data) {
            return result.data.list || [];
        }
        throw new Error(result.message || '获取记忆失败');
    } catch (error) {
        console.error('获取 SecondMe 记忆失败:', error);
        throw error;
    }
}
```

#### 修改 getRedirectUri 方法

getRedirectUri() {

## 🐛 修复的问题

### 问题 1: OAuth 回调地址不匹配

**错误信息**：
```
回调地址不匹配
Application not found
```

**原因**：
- 创建了新的 `secondme-memories.html` 页面
- 但 OAuth 回调地址仍然指向旧页面

**解决方案**：
更新 `services.js` 中的 `getRedirectUri()` 方法，固定回调到 `secondme-memories.html`

**正确的回调地址**：
- 本地开发：`http://localhost:5173/pages/mobile/secondme-memories.html`
- 生产环境：`https://your-domain.com/pages/mobile/secondme-memories.html`

**需要在 SecondMe 开发者控制台配置此回调地址**

### 问题 2: SecondMe 记忆加载失败

**错误信息**：
```
TypeError: Cannot read properties of undefined (reading 'substring')
    at secondme-memories.html:473:103
```

**原因**：
SecondMe API 返回的数据结构与代码中使用的字段不匹配

**SecondMe API 实际返回的字段**：
```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 456,
        "factObject": "兴趣爱好",        // 分类
        "factContent": "喜欢阅读科幻小说", // 内容
        "createTime": 1705315800000,
        "updateTime": 1705315800000
      }
    ],
    "total": 100
  }
}
```

**代码中错误使用的字段**：
- `memory.category` ❌ → 应该是 `memory.factObject` ✅
- `memory.content` ❌ → 应该是 `memory.factContent` ✅
- `memory.title` ❌ → 需要从 `factContent` 截取生成 ✅

**解决方案**：
更新 `renderMemories` 函数，使用正确的字段名

**修复后的代码**：
```javascript
function renderMemories(memories) {
    const grid = document.getElementById('memoriesGrid');
    let html = '';

    memories.forEach(memory => {
        // SecondMe API 返回的字段：factObject (分类), factContent (内容)
        const category = memory.factObject || '个人记忆';
        const content = memory.factContent || '';
        const config = getCategoryConfig(category);
        const dateStr = memory.createTime ? new Date(memory.createTime).toLocaleDateString('zh-CN', { 
            year: 'numeric', 
            month: 'long', 
            day: 'numeric' 
        }) : '';
        
        // 生成标题：取内容的前20个字符
        const title = content.length > 20 ? content.substring(0, 20) + '...' : content;
        
        html += `
            <div class="memory-card">
                <div class="memory-card-header">
                    <div class="memory-icon ${config.class}">${config.icon}</div>
                    <div class="memory-content">
                        <div class="memory-category">${escapeHtml(category)}</div>
                        <div class="memory-title">${escapeHtml(title)}</div>
                        <div class="memory-text">${escapeHtml(content)}</div>
                        ${dateStr ? `<div class="memory-date">${dateStr}</div>` : ''}
                    </div>
                </div>
            </div>
        `;
    });

    grid.innerHTML = html;
}
```

## 📝 技术要点

### SecondMe API 字段映射

| 用途 | SecondMe API 字段 | 说明 |
|------|------------------|------|
| 分类 | `factObject` | 事实对象/分类（如"兴趣爱好"） |
| 内容 | `factContent` | 事实内容（记忆的具体内容） |
| 创建时间 | `createTime` | 毫秒时间戳 |
| 更新时间 | `updateTime` | 毫秒时间戳 |
| ID | `id` | 软记忆 ID |

### OAuth 回调处理流程

1. 用户点击"连接"按钮 → 跳转到 SecondMe 授权页面
2. 用户完成授权 → SecondMe 重定向到 `secondme-memories.html?code=xxx&state=xxx`
3. 页面自动处理回调：
   - 验证 state 参数
   - 交换 authorization code 为 access token
   - 获取用户信息
   - 保存到 localStorage
4. 清除 URL 参数 → 重定向到干净的 `secondme-memories.html`
5. 自动加载 SecondMe 记忆

## ⚠️ 注意事项

1. **必须在 SecondMe 开发者控制台添加回调地址**
   - 本地开发：`http://localhost:5173/pages/mobile/secondme-memories.html`
   - 生产环境：使用 https 协议的完整域名

2. **桌面模式要求**
   - SecondMe OAuth 授权必须在桌面浏览器模式下进行
   - Chrome DevTools 设备模拟模式会导致授权失败
   - 页面已添加自动检测和提示

3. **数据结构**
   - 使用 SecondMe API 的正确字段名：`factObject`、`factContent`
   - 不要使用 `category`、`content`、`title` 等字段
