## 常见问题排查

### 1. 城市信息无效

**症状**：city字段为空、null或"未知城市"

**解决**：运行修复脚本
```bash
node src/database/fix-saved-record-city.js
```

### 2. 坐标信息无效

**症状**：lat或lng为0或null

**解决**：检查保存记录时是否正确传递了坐标

### 3. 用户未登录

**症状**：返回401或403错误

**解决**：确保前端已登录，session有效

### 4. 记录不存在

**症状**：返回404错误

**解决**：检查recordId是否正确

### 5. 数据库连接失败

**症状**：返回500错误，日志显示数据库错误

**解决**：
- 检查PostgreSQL是否运行
- 检查.env配置是否正确
- 检查数据库连接

## 下一步优化

### 1. 前端验证

在发布前验证：
- city不为空且不是"未知城市"
- lat和lng有效
- 至少有原图或生成图

### 2. 后端验证

增加更严格的验证：
```javascript
if (!record.city || record.city === '未知城市') {
  return res.status(400).json({ 
    success: false, 
    error: '城市信息无效，请重新选择位置' 
  });
}

if (!record.lat || !record.lng) {
  return res.status(400).json({ 
    success: false, 
    error: '坐标信息无效' 
  });
}
```

### 3. 用户提示

发布失败时给出更友好的提示：
- "位置信息不完整，请重新选择"
- "图片生成失败，请重试或使用原图"
- "网络错误，请稍后重试"

### 4. 重试机制

发布失败后允许用户重试，而不是直接禁用按钮。
