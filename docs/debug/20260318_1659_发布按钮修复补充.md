## 四、发布功能工作流程

### 4.1 点击加号按钮

```javascript
// 用户点击加号
onclick="togglePublishMenu()"

// 调用 publish-modal.js 中的函数
function togglePublishMenu() {
    const modal = document.getElementById('publishModal');
    if (modal.classList.contains('show')) {
        closePublishModal();
    } else {
        modal.style.display = 'block';
        setTimeout(() => modal.classList.add('show'), 10);
        getCurrentLocation(); // 预先获取位置
    }
}
```

### 4.2 弹窗显示动画

```css
/* 初始状态：隐藏在底部 */
.publish-menu {
    bottom: -100%;
}

/* 显示状态：从底部滑入 */
.publish-modal-overlay.show .publish-menu {
    bottom: 0;
    transition: bottom 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}
```

### 4.3 用户选择发布方式

- **从相册选择** → `selectFromGallery()` → 打开图片编辑器
- **相机** → `openCamera()` → 打开相机拍照
- **写文字** → `openTextEditor()` → 打开文字编辑器
- **取消** → `closePublishModal()` → 关闭弹窗

## 七、关键技术点

### 7.1 CSS 层级管理

```css
/* 导航栏 z-index: 1000 */
.bottom-nav { z-index: 1000; }

/* 发布弹窗 z-index: 2000 */
.publish-modal-overlay { z-index: 2000; }
```

确保发布弹窗在导航栏上方显示。

### 7.2 动画效果

使用 CSS transition 和 cubic-bezier 缓动函数：

```css
transition: bottom 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275);
```

创建弹性滑入效果，提升用户体验。

### 7.3 背景模糊

```css
backdrop-filter: blur(2px);
```

为遮罩层添加模糊效果，突出弹窗内容。
