# AI图片生成审查问题解决方案

## 问题描述

在 `saved-post-records.html` 页面使用AI生成电影风格图片时，出现"图片生成失败：内容审查触发"的错误。

## 根本原因

StepFun API 的内容审查机制被触发，返回错误：
```json
{
  "error": {
    "message": "The content you provided or machine outputted is blocked.",
    "type": "censorship_blocked"
  }
}
```

可能的触发原因：
1. **提示词过于复杂**：包含大量描述性文字，可能包含敏感词汇
2. **原图内容问题**：上传的照片可能包含不适当内容
3. **电影名称误判**：某些电影名称或风格描述可能被误判为敏感内容
4. **生成参数过激**：AI生成强度过高，导致输出内容偏离原图过多

## 解决方案

### 1. 优化提示词生成逻辑

**修改前**：
```javascript
function buildMovieEditPrompt(record, movieName, styleAnalysis) {
    return [
        `将这张旅行记录图片改写为《${movieName}》风格的电影剧照。`,
        `整体风格：${styleAnalysis.movie_style}。`,
        `情绪基调：${styleAnalysis.movie_emotion}。`,
        // ... 大量复杂描述
    ].filter(Boolean).join(' ');
}
```

**修改后**：
```javascript
function sanitizePromptText(text = '') {
    // 移除可能触发审查的敏感词汇和特殊字符
    return String(text || '')
        .replace(/[【】\[\]《》<>""'']/g, '')
        .replace(/\s+/g, ' ')
        .trim()
        .slice(0, 800);
}

function buildMovieEditPrompt(record, movieName, styleAnalysis) {
    const parts = [
        `电影风格旅行照片`,
        styleAnalysis.color_tone ? `色调${styleAnalysis.color_tone}` : '',
        styleAnalysis.filter_effect ? `${styleAnalysis.filter_effect}` : '',
        locationName ? `地点${locationName}` : '',
        mood ? `氛围${mood}` : '',
        '电影感光影，高质量摄影'
    ].filter(Boolean);

    return sanitizePromptText(parts.join('，'));
}
```

### 2. 调整图片生成参数

**修改前**：
```javascript
{
    source_weight: 0.55,  // 原图权重较低
    steps: 50,            // 生成步数较多
    cfg_scale: 7.5        // 引导强度较高
}
```

**修改后**：
```javascript
{
    source_weight: 0.65,  // 提高原图权重，减少AI改动
    steps: 40,            // 减少步数，降低过度生成
    cfg_scale: 6.5        // 降低引导强度
}
```

### 3. 改进错误提示

**修改前**：
```javascript
throw new Error('图片生成失败：内容审查触发');
```

**修改后**：
```javascript
throw new Error('内容审查触发，请尝试：1) 更换电影名称 2) 简化描述 3) 更换原图');
```

## 用户使用建议

### 避免审查触发的最佳实践

1. **选择合适的电影名称**
   - ✅ 推荐：《千与千寻》、《你的名字》、《重庆森林》
   - ❌ 避免：包含敏感词汇的电影名称

2. **使用清晰的旅行照片**
   - ✅ 推荐：风景照、建筑照、美食照
   - ❌ 避免：人物特写、模糊照片、包含文字的照片

3. **简化记录内容**
   - ✅ 推荐：简短的地点和心情描述
   - ❌ 避免：过长的文字、复杂的情节描述

4. **如果仍然失败**
   - 尝试更换不同的电影名称
   - 简化标题和内容描述
   - 更换原始图片
   - 联系技术支持
