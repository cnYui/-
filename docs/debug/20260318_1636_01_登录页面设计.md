# 登录页面设计 (login.html)

**版本**: MVP v1.0  
**优先级**: P0 - 核心功能  
**依赖**: 无

---

## 一、功能概述

用户进入应用的第一个页面，实现强制登录和用户名去重。

---

## 二、用户流程

```
用户访问任意页面
    ↓
auth-check.js 检查 localStorage
    ↓
未登录 → 跳转到 login.html
    ↓
输入用户名
    ↓
后端检查用户名是否存在
    ↓
├── 存在 → 直接登录，返回用户信息
└── 不存在 → 创建新用户，返回用户信息
    ↓
存储到 localStorage
    ↓
跳转到地图首页
```

## 四、前端逻辑

### 4.1 登录流程

```javascript
async function handleLogin() {
  const username = document.getElementById('usernameInput').value.trim();
  const nickname = document.getElementById('nicknameInput').value.trim();
  
  if (!username) {
    showHint('请输入用户名');
    return;
  }
  
  try {
    showLoading('登录中...');
    
    const response = await fetch('/api/users', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ 
        username, 
        nickname: nickname || username 
      })
    });
    
    const result = await response.json();
    
    if (result.success) {
      // 存储用户信息
      localStorage.setItem('current_user_id', result.data.id);
      localStorage.setItem('user_info', JSON.stringify(result.data));
      
      // 跳转到首页
      window.location.href = '/';
    } else {
      showHint(result.error || '登录失败');
    }
  } catch (error) {
    showHint('网络错误，请重试');
  } finally {
    hideLoading();
  }
}
```

### 4.2 auth-check.js 强制登录

```javascript
// 在所有页面引入此脚本
(function() {
  const userId = localStorage.getItem('current_user_id');
  const currentPath = window.location.pathname;
  
  // 登录页面不检查
  if (currentPath.includes('login.html')) return;
  
  // 未登录则跳转
  if (!userId) {
    window.location.href = '/pages/mobile/login.html';
  }
})();
```

## 五、后端 API

### 5.1 POST /api/users

**请求**:
```json
{
  "username": "zhangsan",
  "nickname": "张三"
}
```

**响应（成功）**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "username": "zhangsan",
    "nickname": "张三",
    "avatar": null,
    "bio": null,
    "created_at": "2026-03-18T15:00:00"
  },
  "isNewUser": true
}
```

**响应（用户已存在）**:
```json
{
  "success": true,
  "data": { ... },
  "isNewUser": false
}
```

## 六、数据库

### 6.1 users 表

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL UNIQUE,
    nickname TEXT NOT NULL,
    avatar TEXT,
    bio TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
