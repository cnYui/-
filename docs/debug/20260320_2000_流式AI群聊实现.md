# 流式AI群聊实现说明

## 📅 时间
2026-03-20 20:00

## 🎯 目标
实现真正的串行对话生成，使用SSE流式输出，让AI群聊一条一条自然生成。

## 🔧 实现方案

### 1. 对话生成逻辑
**之前的问题：**
- 所有用户同时并行回复
- 没有对话的连贯性
- 使用硬编码的fallback模板

**新的实现：**
- 串行生成：A发言 → B回复 → C回复 → A追问
- 每条消息都调用真实的AI API
- 使用SSE (Server-Sent Events) 实时推送

### 2. 生成顺序
```
1. 发帖人开场白 (opening)
   ↓
2. 其他成员回复 (reply) - 随机选3人
   ↓
3. 发帖人追问 (followup)
   ↓
4. 其他成员继续回复 (reply) - 再选2人
```

### 3. API接口

#### 创建聊天室
```
POST /api/chatrooms/create-by-location
```

**变更：**
- 不再在创建时生成AI对话
- 返回 `needsGeneration: true` 标记
- 前端需要调用流式生成接口

**响应：**
```json
{
  "success": true,
  "data": {
    "chatroomId": 10,
    "chatroomName": "玄武区·古鸡鸣寺附近",
    "matchedUsers": [...],
    "memberCount": 9,
    "needsGeneration": true
  }
}
```

#### 流式生成AI群聊
```
POST /api/chatrooms/:chatroomId/generate-stream
```

**请求头：**
```
Content-Type: application/json
X-User-Id: 53
```

**请求体：**
```json
{
  "maxMessages": 6
}
```

**响应：** SSE流式事件

**事件类型：**

1. `start` - 开始生成
```json
{
  "type": "start",
  "memberCount": 9,
  "maxMessages": 6
}
```

2. `generating` - 正在生成某人的消息
```json
{
  "type": "generating",
  "speaker": "鱼尾呀",
  "role": "reply"
}
```

3. `message` - 生成完成一条消息
```json
{
  "type": "message",
  "messageId": 123,
  "userId": 229,
  "nickname": "鱼尾呀",
  "avatar": "...",
  "content": "如果你还想继续逛，我推荐去玄武湖...",
  "role": "reply"
}
```

4. `done` - 全部生成完成
```json
{
  "type": "done",
  "totalMessages": 6
}
```

5. `error` - 发生错误
```json
{
  "type": "error",
  "message": "错误信息"
}
```

### 4. 前端集成示例

```javascript
async function generateChatroom(chatroomId) {
    const response = await fetch(`/api/chatrooms/${chatroomId}/generate-stream`, {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'X-User-Id': userId
        },
        body: JSON.stringify({ maxMessages: 6 })
    });
    
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    
    while (true) {
        const { done, value } = await reader.read();
        if (done) break;
        
        const chunk = decoder.decode(value);
        const lines = chunk.split('\n');
        
        for (const line of lines) {
            if (line.startsWith('data: ')) {
                const data = JSON.parse(line.substring(6));
                
                switch (data.type) {
                    case 'generating':
                        showGenerating(data.speaker, data.role);
                        break;
                    case 'message':
                        addMessage(data);
                        break;
                    case 'done':
                        showComplete();
                        break;
                }
            }
        }
    }
}
```
