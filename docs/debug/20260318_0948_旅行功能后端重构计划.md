# 旅行功能后端重构计划

## 📅 创建时间
2026年3月18日 09:48

## 🎯 重构目标

将原始项目 `agenTravel` 中的旅行计划生成功能迁移到 `明日旅途` 项目，实现前后端分离架构下的旅行功能。

## 📋 原始项目流程分析

### 用户使用流程
1. **journey.html** - 选择日期，上传行程记录
2. **地图页面** - 显示用户上传的记录（表情打点）
3. **myhouse.html** - 选择图片进行影视化构建
4. **memory.html** - 管理影视化项目并发布到世界
5. **agent-travel.html** - 查看所有人发布的帖子（地图展示）
6. **开始旅行** - 填写出发地 → 选择旅行方式和目的地 → 生成旅行计划

### 旅行计划生成流程
1. 用户在"我的房间"填写出发地
2. 在"地图旅行"页面点击"开始旅行"
3. 弹窗选择旅行方式和目的地
4. 点击"开始旅行"按钮
5. 后端调用 DeepSeek API 生成 JSON 结构的旅行日志
6. 前端显示旅行计划
7. 每结束一天，系统在旅行日记中添加一篇日记

## 📊 数据模型设计

### travel_plans 表
```sql
CREATE TABLE travel_plans (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    departure TEXT,
    destination TEXT,
    travel_mode TEXT,
    days INTEGER,
    plan_json TEXT,
    start_time DATETIME,
    status TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### travel_diaries 表
```sql
CREATE TABLE travel_diaries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    plan_id INTEGER,
    day INTEGER,
    content TEXT,
    images TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
