- `travel.js` - 旅行功能 API 路由

  - `POST /api/travel/plan/start` - 开始旅行
  - `GET /api/travel/progress/:userId` - 获取旅行进度（自动推进）
  - `GET /api/travel/plans/:userId` - 获取旅行计划列表
  - `GET /api/travel/diaries/:planId` - 获取旅行日记

  - `DATABASE_PATH` - 数据库路径
  - `DEEPSEEK_API_KEY` - DeepSeek API 密钥
  - `AMAP_KEY` - 高德地图 API 密钥
  
- `src/routes/index.js` - 集成旅行路由

### 3. 后端计时功能

#### 实现原理
1. **expected_complete_time 字段** - 预计完成时间（精确到秒）
2. **自动推进逻辑** - 在 `GET /api/travel/progress/:userId` 中实现
   - 每次请求时检查当前时间是否超过预计完成时间
   - 如果超过，自动推进到下一个景点
   - 更新进度表和预计完成时间
3. **测试模式** - 每个景点停留 5 秒
4. **日记生成** - 每天结束时调用 DeepSeek 生成日记

#### 流程示例
```
景点 1: 西湖 (5秒) → 景点 2: 灵隐寺 (5秒) → 景点 3: 宋城 (5秒)
         ↓                      ↓                      ↓
     第1天结束              第2天开始              第2天结束
         ↓                                              ↓
   生成第1天日记                                  生成第2天日记
```

## ⚠️ 已知问题

### 1. CommonJS vs ES6 模块冲突
后端文件使用了 CommonJS 格式（`require/module.exports`），但项目配置为 ES6 模块（`"type": "module"`）。

**需要转换的文件：**
- `backend/src/database/init-travel.js`
- `backend/src/services/deepseek.js`
- `backend/src/services/travel-plan-generator.js`
- `backend/src/routes/travel.js`

**解决方案：**
将所有 `require` 改为 `import`，`module.exports` 改为 `export`。

### 2. 缺少依赖
需要安装：
```bash
cd backend
npm install axios better-sqlite3
```

### 3. 数据库初始化
需要在 `backend/src/index.js` 中调用数据库初始化函数。
