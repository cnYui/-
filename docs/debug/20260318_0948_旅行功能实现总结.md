## ⚠️ 注意事项

### CommonJS vs ES6 模块
后端文件创建时使用了 CommonJS 格式（`require/module.exports`），但项目使用 ES6 模块（`import/export`）。

**需要转换的文件：**
1. `backend/src/database/init-travel.js`
2. `backend/src/services/deepseek.js`
3. `backend/src/services/travel-plan-generator.js`
4. `backend/src/routes/travel.js`

**转换方法：**
```javascript
// CommonJS
const express = require('express');
module.exports = { func };

// ES6
import express from 'express';
export { func };
```

## 📝 用户流程

1. 用户打开 `mobile-index.html`（地图页面）
2. 点击"开始旅行"按钮
3. 弹窗选择旅行方式、出发地、目的地
4. 点击"开始旅行"
5. 后端调用 DeepSeek 生成旅行计划（约10-30秒）
6. 前端显示旅行计划并开始计时
7. 每个景点停留 5 秒后自动切换
8. 每天结束时后端自动生成日记
9. 全部景点完成后旅行结束
