# 图片上传和发布功能修复

## 问题1：AI图片生成失败 - 图片分辨率过大

### 错误信息

```
❌ AI 图片生成失败: Error: 电影风格图片生成失败: 
Request param: source_url is invalid, recommended val is: 
The image resolution provided in the request (source_url) is too large. 
limit width: [0:2048], limit height: [0:2048], 
limit size: 10485760, limit pixels: 0, 
current source_url image width: 2656, height: 1600, 
size: 1100888, pixels: 4249600
```

### 根本原因

上传的原图分辨率为 2656x1600，超过了 StepFun API 的限制（最大 2048x2048）。

### 解决方案

#### 1. 修改上传接口（backend/src/routes/upload.js）

在图片上传时就进行压缩和缩放：

**关键改动：**
- 使用 `multer.memoryStorage()` 先将图片加载到内存
- 使用 `sharp` 库进行图片处理
- 缩放策略：`fit: 'inside'` - 保持宽高比，不裁切，最大边不超过2048
- 压缩策略：转换为JPEG格式，质量85%
- 统一输出为 `.jpg` 格式

**处理流程：**
```javascript
1. 接收上传的图片（内存中）
2. 使用sharp读取图片元数据
3. 如果宽或高超过2048，按比例缩放
4. 转换为JPEG格式并压缩（质量85%）
5. 保存到磁盘
6. 返回文件URL
```

**效果：**
- 原图：2656x1600，1100KB
- 处理后：2048x1234（保持宽高比），约500-700KB
- 压缩率：约40-50%

#### 2. 修改StepFun服务（backend/src/services/stepfun.js）

增加图片压缩函数作为双重保险：

```javascript
async function compressImageBuffer(buffer, mimeType) {
    const image = sharp(buffer);
    const metadata = await image.metadata();
    
    if (metadata.width > 2048 || metadata.height > 2048) {
        return await image
            .resize(2048, 2048, {
                fit: 'inside', // 保持宽高比
                withoutEnlargement: true
            })
            .jpeg({ quality: 85 })
            .toBuffer();
    }
    
    return buffer;
}
```

#### 3. 安装依赖

```bash
cd backend
npm install sharp
```

### 验证

上传一张大图（如3000x2000），系统会自动：
1. 缩放到2048x1365（保持宽高比）
2. 压缩为JPEG格式
3. 文件大小减少40-50%
4. 可以正常用于AI图片生成

## 注意事项

1. **图片格式**
   - 上传后统一转换为JPEG格式
   - 原始PNG/WebP会被转换

2. **图片质量**
   - 压缩质量设置为85%
   - 平衡文件大小和画质

3. **城市信息**
   - 必须有效，不能是"未知城市"
   - 发布前会自动验证

4. **坐标信息**
   - 必须有效，不能为0或null
   - 用于地图显示和聊天室匹配
