# 收信箱日记图片生成功能迁移

## 📅 迁移时间
2026年3月18日 10:30

## 📦 迁移内容

### 需求概述
将原始项目 `agenTravel` 中的旅行日记生成和图片生成功能迁移到新项目 `明日旅途`，并以"收信箱"的形式展示日记。

### 核心功能
1. **收信箱列表页（notes.html）** - 纯文字展示所有日记/信件
2. **信件详情页（note-detail.html）** - 查看详情并可生成旅行图片
3. **后端 API** - 日记管理和图片生成

|------|------|------|
| GET | `/api/diaries/user/:userId` | 获取用户所有日记 |

## ⚠️ 注意事项

1. **StepFun API 密钥**
   - 需要在 `.env` 文件中配置 `STEPFUN_API_KEY`
   - 没有密钥时图片生成会失败

2. **图片生成时间**
   - StepFun 图片生成通常需要 10-30 秒
   - 前端显示加载动画提示用户等待

3. **内容审查**
   - StepFun API 有内容审查机制
   - 如果触发审查（HTTP 451），会返回错误提示

4. **数据持久化**
   - 当前前端使用模拟数据
   - 后续需要对接真实的后端 API 获取日记列表
