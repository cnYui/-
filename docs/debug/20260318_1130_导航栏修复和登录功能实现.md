# 导航栏修复和登录功能实现

## 📅 实现时间
2026年3月18日 11:30

## 🎯 问题和需求

### 问题 1：导航栏链接无法切换
**现象：** 底部导航栏点击后无法切换页面，一直停留在首页

**原因：** 导航栏使用了相对路径（如 `../../index.html`、`encounter.html`），在不同层级的页面中无法正确跳转

### 问题 2：实现用户登录功能
**需求：** 
- 参考原始项目的数据库设计
- 实现简单的用户名登录（无需密码）
- 首次访问时需要登录
- 登录后保存用户信息到 localStorage

---

## ✅ 解决方案

### 1. 数据库设计

参考原始项目 `agenTravel/src/backend/database/schema.sql`，创建完整的数据库表结构：

-- 用户表（与原始项目一致）

    avatar TEXT,

);

-- 旅行计划表
CREATE TABLE IF NOT EXISTS travel_plans (...)

CREATE TABLE IF NOT EXISTS user_memories (...)

**文件：** `backend/src/database/init.js`
- 数据库初始化逻辑
- 启用外键约束
- 执行 schema.sql

### 2. 后端用户路由

**文件：** `backend/src/routes/users.js`

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/users` | 创建/登录用户（自动判断是否已存在） |
| GET | `/api/users/:userId` | 获取用户信息 |
| PUT | `/api/users/:userId` | 更新用户信息 |

**登录逻辑：**
1. 接收 username 和 nickname
2. 检查用户是否已存在
3. 存在则返回现有用户信息
4. 不存在则创建新用户并返回

### 3. 登录页面

**文件：** `frontend/src/pages/mobile/login.html`

**特点：**
- Neo-Brutalism 设计风格
- 只需输入用户名即可登录
- 自动检测已登录状态，已登录则跳转首页
- 登录成功后保存到 localStorage

**LocalStorage 存储：**
```javascript
localStorage.setItem('current_user_id', userId);
localStorage.setItem('current_user', JSON.stringify(userData));
```

### 4. 登录检查脚本

**文件：** `frontend/src/js/auth-check.js`

```javascript
// 自动检查登录状态
const userId = localStorage.getItem('current_user_id');
if (!userId && !currentPath.includes('login.html')) {
    window.location.href = '/pages/mobile/login.html';
}
```

### 5. 导航栏链接修复

**修改内容：** 将所有相对路径改为绝对路径

| 原路径 | 新路径 |
|--------|--------|
| `../../index.html` | `/` |
| `encounter.html` | `/pages/mobile/encounter.html` |
| `notes.html` | `/pages/mobile/notes.html` |
| `profile.html` | `/pages/mobile/profile.html` |

**修改文件：**
- `frontend/src/index.html`

- `frontend/src/pages/mobile/notes.html`
- `frontend/src/pages/mobile/encounter.html`

## ⚠️ 注意事项

1. **数据库文件位置**
   - 默认：`backend/src/database/travel.db`
   - 可通过环境变量 `DATABASE_PATH` 修改

2. **登录状态持久化**
   - 使用 localStorage 存储
   - 关闭浏览器后仍然保持登录状态
   - 清除浏览器缓存会退出登录

3. **导航栏链接**
   - 统一使用绝对路径（以 `/` 开头）
   - 确保在任何页面都能正确跳转

4. **Vite 配置**
   - `root: 'src'` - 根目录设置为 src
   - 所有绝对路径都相对于 src 目录

## 🐛 调试提示

### 如果登录页面无限循环
检查 `auth-check.js` 中的路径判断逻辑

### 如果导航栏跳转 404
检查 Vite 配置中的 `root` 设置和路径是否正确

### 如果数据库初始化失败
检查 `backend/src/database/` 目录权限

### 如果后端 API 调用失败
检查 Vite proxy 配置和后端服务是否启动
