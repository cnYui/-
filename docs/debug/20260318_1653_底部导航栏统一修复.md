    bottom: 8px;

**我的页面 (profile.html)** - 正常

### 1.2 发布按钮问题

| 页面 | 按钮代码 | 问题 |
|------|---------|------|
| notes.html | `<div onclick="togglePublishMenu()">` | ✅ 正常 |

## 二、修复方案

### 2.1 统一导航栏样式

以 `notes.html` 为标准，统一所有页面的导航栏 CSS：

```css
/* 固定高度 70px */
.bottom-nav {
    position: fixed;
    bottom: 0;
    left: 0;
    width: 100%;
    height: 70px;
    background-color: #fff;
    border-top: var(--border-width) solid var(--border-color);
    display: flex;
    justify-content: space-around;
    align-items: center;
    z-index: 1000;
}

/* 导航项占满高度 */
.nav-item {
    flex: 1;
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    text-decoration: none;
    color: var(--text-color);
    font-weight: bold;
    font-size: 12px;
    height: 100%;
    transition: all 0.2s ease;
}

/* 图标大小和间距 */
.nav-icon {
    font-size: 22px;
    margin-bottom: 2px;
}

/* 加号按钮容器 */
.center-add-wrapper {
    flex: 1;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100%;
}

/* 加号按钮 - 使用 margin-bottom 而非 absolute */
.center-add-btn {
    width: 50px;
    height: 50px;
    border-radius: 50%;
    background-color: var(--accent-yellow);
    border: 4px solid var(--border-color);
    display: flex;
    justify-content: center;
    align-items: center;
    font-size: 30px;
    font-weight: bold;
    color: var(--text-color);
    text-decoration: none;
    box-shadow: 3px 3px 0 rgba(0,0,0,1);
    transition: all 0.2s ease;
    cursor: pointer;
    margin-bottom: 5px;  /* 关键：固定边距 */
}
```

### 2.2 统一发布按钮调用

**HTML 统一格式**：
```html
<div class="center-add-wrapper">
    <div class="center-add-btn" onclick="togglePublishMenu()">
        <i class="ri-add-line"></i>
    </div>
</div>
```

**JavaScript 统一函数**：
```javascript
// publish-modal.js 中添加
function togglePublishMenu() {
    const modal = document.getElementById('publishModal');
    if (!modal) return;
    
    if (modal.classList.contains('show')) {
        closePublishModal();
    } else {
        modal.style.display = 'block';
        setTimeout(() => {
            modal.classList.add('show');
        }, 10);
        
        getCurrentLocation().then(loc => {
            console.log('当前位置:', loc);
        });
    }
}
```

## 五、技术要点

### 5.1 避免抖动的关键

1. **固定高度**：使用 `height: 70px` 而非 `padding`
2. **固定边距**：使用 `margin-bottom: 5px` 而非 `position: absolute`
3. **统一布局**：所有元素使用相同的 flex 布局方式

### 5.2 发布按钮设计

1. **使用 div 而非 a 标签**：避免默认链接行为
2. **使用图标而非文字**：`<i class="ri-add-line"></i>`
3. **统一函数名**：`togglePublishMenu()` 替代 `openPublishModal()`

### 5.3 弹窗管理

1. **显示逻辑**：先设置 `display: block`，再添加 `show` 类触发动画
2. **隐藏逻辑**：先移除 `show` 类，300ms 后设置 `display: none`
3. **位置获取**：打开弹窗时预先获取用户位置，提升发布体验
