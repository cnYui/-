# 编辑资料功能实现

**时间**: 2026-03-18 16:47  
**功能**: 用户编辑资料页面（头像、昵称、简介）

---

## 一、需求说明

用户在个人中心点击"编辑资料"按钮后，进入独立的编辑资料页面，可以修改：
1. **头像** - 支持上传图片
2. **昵称** - 文本输入，最多20字
3. **简介** - 多行文本，最多100字

使用 Neo-Brutalism 设计风格，与项目整体风格保持一致。

### 2.2 后端接口

**已有接口**: `PUT /api/users/:userId`

**请求参数**:
```json
{
  "nickname": "新昵称",
  "avatar": "/uploads/image-xxx.jpg",
  "bio": "新的个人简介"
}
```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "username": "zhangsan",
    "nickname": "新昵称",
    "avatar": "/uploads/image-xxx.jpg",
    "bio": "新的个人简介"
  }
}
```

**数据库表**: `users`
- `nickname` TEXT NOT NULL
- `avatar` TEXT
- `bio` TEXT

### 2.3 图片上传

**接口**: `POST /api/upload/image`

**实现文件**: `backend/src/routes/upload.js`

**功能**:
- 使用 multer 中间件处理文件上传
- 文件保存到 `backend/uploads/` 目录
- 支持格式：jpeg, jpg, png, gif, webp
- 大小限制：5MB
- 自动生成唯一文件名

**返回数据**:
```json
{
  "success": true,
  "data": {
    "url": "/uploads/image-1710748549867-123456789.jpg",
    "filename": "image-1710748549867-123456789.jpg",
    "size": 245678,
    "mimetype": "image/jpeg"
  }
}
```

## 三、用户流程

1. 用户在个人中心点击"编辑资料"
2. 进入编辑资料页面，自动加载当前用户信息
3. 用户可以：
   - 点击头像右下角相机图标上传新头像
   - 修改昵称（必填，最多20字）
   - 修改简介（可选，最多100字）
4. 点击"保存"按钮提交修改
5. 保存成功后自动返回个人中心
6. 个人中心显示更新后的信息

## 四、技术细节

### 4.1 头像上传流程

```javascript
1. 用户选择图片文件
2. 前端验证文件类型和大小
3. 使用 FormData 上传到 /api/upload/image
4. 后端返回图片 URL
5. 前端预览新头像
6. 保存时将 URL 提交到 /api/users/:userId
```

### 4.2 数据验证

**前端验证**:
- 昵称不能为空
- 图片文件类型检查
- 图片大小限制 5MB
- 字符长度限制

**后端验证**:
- 用户存在性检查
- 字段类型验证
- SQL 注入防护（使用参数化查询）

### 4.3 本地存储更新

保存成功后更新 localStorage:
```javascript
const userInfo = JSON.parse(localStorage.getItem('user_info') || '{}');
userInfo.nickname = response.data.nickname;
userInfo.avatar = response.data.avatar;
userInfo.bio = response.data.bio;
localStorage.setItem('user_info', JSON.stringify(userInfo));
```
